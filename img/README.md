# Public image assets

All images here are approved for publication on the official site.

- `scs-logo.png` — **current** SCS emblem, transparent PNG (checkerboard-free, optimized).
  Used in the header, hero and footer (`index.html`).
- `emblem.png`, `emblem-512.png` — legacy emblem art, kept for reference only (no longer
  referenced by the site).
- `screen-*.jpg` — screenshots captured from the real current build (menu, modes,
  buy phase, live TDM match, pause). Replace freely with newer captures; keep the
  same filenames or update `index.html`. Do not add fictional gameplay images.
- `hero-bg.jpg` — hero backdrop (darkened frame from the live build)
- `og.jpg` — social share card (new emblem, no boxed background) · `favicon.png` —
  browser icon (new emblem on the theme-dark background)
