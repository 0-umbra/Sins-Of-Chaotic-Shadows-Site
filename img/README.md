# Public image assets

All images here are approved for publication on the official site.

- `scs-logo.png` — **current** SCS emblem, transparent PNG (`1024×809`, checkerboard-free).
  Served alongside responsive WebP variants (`scs-logo.webp`, `scs-logo-640.webp`, `scs-logo-160.webp`)
  via `<picture>` in header, hero and footer (`index.html`).
- `emblem.png`, `emblem-512.png` — legacy emblem art, kept for reference only (no longer
  referenced by the site).
- `screen-*.webp` / `screen-*.jpg` — screenshots captured from the real current build
  (menu, modes, buy phase, live TDM match, pause). WebP variants reduce bandwidth by ~45–63%
  with JPEG fallbacks preserved. Replace freely with newer captures; do not add fictional
  gameplay images.
- `hero-bg.webp` / `hero-bg.jpg` — hero backdrop (darkened frame from the live build).
- `og.jpg` — social share card (kept in JPEG for OpenGraph scraper compatibility) · `favicon.png` —
  browser icon.
