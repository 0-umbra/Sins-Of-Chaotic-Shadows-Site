QUESTIONS

FAQ

What platforms does SCS run on?

Android (the signed APK on this page) and any modern desktop or mobile browser via the web build. Both are the same game and the same content.

Do I need an account?

No. You can play entirely on-device with local saves. An optional SCS account (Google or email) adds server-verified level, rank, unlock sync and shared settings across devices.

Is ranked play available?

Online ranked matchmaking is disabled — no ranked service is configured. Local career rating is earned against bots, and private rooms are unranked peer-to-peer.

Will installing a new APK wipe my progress?

No — install the new APK over the old build and your local data stays. Do not uninstall first. Every release is signed with the same developer certificate, so Android updates it in place.

How do I verify my download?

Every release publishes a SHA-256 checksum (shown in the Download section). On desktop: sha256sum file.apk (Linux/macOS) or certutil -hashfile file.apk SHA256 (Windows) and compare.

Why does Android warn me when installing?

SCS is distributed directly by the developer rather than through an app store, so Android asks you to allow installs from your browser once. That prompt is standard for sideloaded APKs.

Does the game collect my data?

The game itself has no ads and no analytics. If you opt into an SCS account, your profile, unlocks and settings are stored in the developer's Supabase project under row-level security — see the Privacy summary in the footer.

Where can I report a bug or request a feature?

Open an issue on the public site repository or reach the developer on Discord: scr1pt.fx.

ABOUT THE PROJECT

One developer, no shortcuts

Sins of Chaotic Shadow is an independent tactical FPS project led by a single developer (0-umbra) with an explicit rule: nothing on this site or in the game pretends to be something it isn't. Ranked is disabled until a real ranked service exists. Progress is server-verified or it is called local. Weapon sounds are synthesized, not sampled. The screenshots above come from the shipped build.

The game is built on Three.js with peer-to-peer multiplayer over PeerJS, optional accounts on Supabase, and ships to Android through Capacitor. SCS is not affiliated with, sponsored by or endorsed by the vendors of those technologies. Android is a trademark of Google LLC.
