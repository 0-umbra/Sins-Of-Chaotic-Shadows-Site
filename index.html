RELEASE NOTES // OPTIMIZATION PASS

What's New in This Build

The package served here is SCS.apk — 7.86 MB (8,244,435 bytes), versionName 0.22.1, versionCode 3. Every item below is present in that signed file. These notes describe what changed; they do not publish measured frame rates.

PART 4 + PART 5

Performance optimizations

  • Reduced rendering workload for visible objects: character detail now steps down with distance (detail tiers from 24 m and 45 m, with hysteresis so it does not flicker), and parts too small to resolve are hidden and stop casting shadows at range.
  • Batched character rendering: static parts that never move relative to a bone — armour plates, straps, hair pieces — are merged per bone, material and size class, so the same silhouette costs fewer draw calls. Animatable parts (cape, tails, skirts, crests, core, held weapon) are never merged.
  • Fewer shadow casters, fewer shadow-map renders: the sun shadow map is re-rendered only when it is due (never older than one 60 Hz frame, and forced on quality, map or context changes) instead of every frame.
  • Fewer avoidable per-frame allocations: bot shooting and bullet updates reuse preallocated scratch math, and one reused state object feeds the viewmodel instead of a fresh literal 60–120 times a second.
  • Adaptive graphics quality with cooldown and back-off: sustained pressure lowers shadows → effects → view distance in steps; a restore needs a long run of headroom, doubles its wait if pressure returns, and holds the level after repeated flaps. Any manual graphics change resets everything to your own settings.
  • Deeper frame-time monitoring: the in-game FPS readout now reports p50, p95, p99, maximum frame time, the share of late frames and a hitch count — not just an average.

Movement and stability

  • Frame-rate-independent movement acceleration: the velocity chase now uses an exponential response tuned to reproduce the previous 60 fps feel exactly, so acceleration no longer changes with frame rate or the frame cap.
  • Consistent jump apex at any frame rate: vertical motion runs in exact constant-acceleration sub-steps of at most 1/120 s, so the trajectory is the same parabola whether the phone presents 30, 60 or 120 frames. The package uses a 7.4 m/s jump velocity against 22 m/s² gravity (≈ 1.245 m apex, still clearing the 1.4 m cover boxes); slide-jump is 8.9 m/s.
  • Better frame pacing after backgrounding: returning from the background or a WebView restore resets the frame limiter, the accumulated-time debt, the adaptive governor's warm-up, the frame statistics and the shadow map — so the first frame back is bounded instead of a catch-up burst. Match state is not touched.
  • Automated tests added in the game repository: the new optimization and physics modules are deliberately pure (no DOM, no timers) so headless suites can drive them, and the character builder keeps an unbatched path for batching-equivalence tests.

Testing status and honest limits

  • Test suites: the Part 4 and Part 5 suites were reported to pass by the development workflow that produced this APK. This website repository cannot run them, so no final test count is published here.
  • What the numbers mean: batching, detail tiers and shadow cadence target draw calls and shadow-caster count. That is the documented goal plus desktop/headless checks — not a measured Android FPS gain.
  • No performance guarantee: there is no guaranteed 60 FPS, no “zero lag”, and no claim of a verified improvement on every Android phone.
  • No device verification claimed: this build has not been measured on real Android hardware here, including a Moto e13 run. Lighting and shadow timing on device remain unverified.
  • Nothing new to unlock: this pass adds no new weapons, maps, modes, multiplayer features or other gameplay content. Version identity stays versionName 0.22.1 / versionCode 3 — confirm the SHA-256 above rather than the number.

DIAGNOSTICS

Android Troubleshooting Guide

Lag, frame drops, or overheating mid-match

Open Settings → Render Control and drop Render Quality to 75% or 50%, set Shadow Quality to Off, Effects Quality to Low, and View Distance to Low. Cap Target FPS to 30 FPS or 60 FPS instead of uncapped refresh rates, close background social/video apps, and avoid fast-charging while playing to prevent thermal CPU/GPU throttling.

Black screen, WebGL error, or crash on startup

SCS renders 3D arenas through Android's system WebGL driver. Update Android System WebView and Google Chrome in the Play Store, then restart your phone. On low-memory devices, set Texture Quality to Low. Also verify your mobile data or Wi-Fi connection is active, as offline startup is not yet enabled.

“App not installed”, package parse error, or Play Protect warning

First verify your device runs Android 7.0 or newer and that the downloaded SCS.apk is complete (8,244,435 bytes, SHA-256 04cf9290c3fc04364ea149d9f346b0e5e7517c76e3a112f77d414669b0f6d9cf) — an interrupted browser download causes “problem parsing the package”. Enable Install unknown apps for your browser once, and if Google Play Protect prompts you, tap “Scan app” and proceed once scanning finishes.

Updating to a newer APK version without losing progress

Download the new /apk/SCS.apk and install it directly over your existing app — do not uninstall SCS first. All official releases use package com.sinsofchaoticshadow.game signed with the same developer certificate, so Android upgrades cleanly in place while keeping local data. Using an SCS cloud account additionally syncs level, rank, unlocks, and settings across devices.

Download the signed Android APK on this page. Browser gameplay is not currently available because the latest maps are not available for the browser build.

Do I need an account?

SCS accounts support server-verified level, rank, unlock sync and shared settings across devices. Offline gameplay is planned for a future update; it is not currently available.

Is ranked play available?

Online ranked matchmaking is disabled — no ranked service is configured. Local career rating is earned against bots, and private rooms are unranked peer-to-peer.

Will installing a new APK wipe my progress?

No — install the new APK over the old build and your local data stays. Do not uninstall first. Every release is signed with the same developer certificate, so Android updates it in place.

How do I verify my download?

Every release publishes a SHA-256 checksum (shown in the Download section). On desktop: sha256sum file.apk (Linux/macOS) or certutil -hashfile file.apk SHA256 (Windows) and compare.

Why does Android warn me when installing?

SCS is distributed directly by the developer rather than through an app store, so Android asks you to allow installs from your browser once. That prompt is standard for sideloaded APKs.

Does the game collect my data?

The game itself has no ads and no analytics. When you use an SCS account, your profile, unlocks and settings are stored in the developer's Supabase project under row-level security — see the Privacy summary in the footer.

Where can I report a bug or request a feature?

Website issue reporting is currently under development and will be available in a future update. For now, please Contact the Developer on Discord.
